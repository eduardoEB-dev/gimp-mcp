Beagle Dog Bowl Candle Holder Snow Base (X2D)

An optional snow base for the Beagle Dog Bowl Candle Holder: a round base with snow drifts and snowballs that the sitting beagle rests in. Printed in white PLA.

This file contains the snow base only. The beagle figure, bowl, collar, head and ears are in the Beagle Dog Bowl Candle Holder release.

Set up for the Bambu Lab X2D (0.4 nozzle, 0.20mm Standard, PLA). Plates: 1 snow base (white).

Candle safety: use a jar candle only, keep the figure on a stable surface, and never leave a burning candle unattended.
